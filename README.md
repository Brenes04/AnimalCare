# Animal Care

## Sistema de Gestión Veterinaria
Animal Care es una aplicación desarrollada en Java para gestionar información de una clínica veterinaria. El sistema permite administrar propietarios, mascotas, veterinarios, especialidades y citas médicas.

## Tecnologías utilizadas
- Java
- Java Swing
- Programación Orientada a Objetos (POO)
- IntelliJ IDEA

## Funcionalidades
- Registro y gestión de propietarios
- Registro y gestión de mascotas
- Gestión de veterinarios
- Gestión de especialidades
- Agendamiento de citas médicas
- Generación de reportes
- Validación de datos

## Conceptos aplicados
Durante el desarrollo se aplicaron conceptos de programación orientada a objetos como:

- Encapsulamiento
- Herencia
- Polimorfismo
- Clases y objetos
- Manejo de listas
- Validación de datos
- Interfaces gráficas con Java Swing
